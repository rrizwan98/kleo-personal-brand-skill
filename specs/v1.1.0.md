# v1.1.0 — Curated writing library and evidence-aware selection

Date: 2026-10-14. Compatible minor release; client-state migration is not required.

## Problem and intended behavior

v1.0.1 supplies eight general writing structures but no packaged, searchable template or real-example collection. The approved update adds 40 original template cards and 24 independently observed public LinkedIn reference cards. It does not import the unlicensed third-party template vault or claim to contain Kleo's proprietary templates.

For a drafting request, resolve the client's reader, product, goal, pillar, permitted evidence and voice. Shortlist eligible structures, inspect only relevant cards, choose or adapt one, write original content, check factual ownership and preserve a short selection trace outside the post body. Templates never supply client facts or substitute for voice evidence.

## Acceptance criteria

- 40 distinct original cards cover education, authority, trust, demand and conversation, with audience/pillar tags, required evidence, opening type, ordered development, CTA options and misuse limits.
- 24 reference cards have direct public-post URLs, visible author, observation date, access scope, brief original structural notes and limitations. No full third-party posts, screenshots, comments or proprietary template dumps are redistributed.
- Reference cards make no verified-growth, Kleo-authorship, current-role or causal-performance claim. Metrics and exact publication dates remain unknown unless explicitly verified.
- A standard-library Python selector filters unavailable evidence before ranking compatible goals, audiences and pillars. It returns a bounded shortlist with reasons, recent-template penalties and selected example cards. No eligible match yields an honest empty result.
- The assistant can select manually if Python is unavailable. A minimal rewrite keeps an effective existing structure; a supplied user structure takes priority. A template can be rejected when it would harm the idea or voice.
- Save optional template/example IDs and selection rationale on the current post record. Older records without these fields still work.
- Compare v1.0.1 and v1.1.0 on the same three fictional briefs, retaining both drafts and an explicit evaluator limitation. Include unsupported-proof handling, different voices and an offer-fit case. Do not claim a blind, independent or live-Kleo test.
- Run selector regressions, existing initializer tests, metadata/link/package checks, the three Skill Creator Max maintenance reviews and public-content review. Package, install and version the final result.

## Scope limits

This adds structured writing resources and retrieval, not a publishing backend, extension, analytics collector or human coaching service. These original templates are editorial tools, not statistically proven formulas. Source authors' stories and metrics must never become the client's experiences. Reading a post verifies the observable text, not the truth of every claim or the identity of its ghostwriter.

## Provenance and maintenance

The original templates are authored for this project. External references contain only links and concise analysis of observable structure. Refresh a reference before using its factual claims; if access is lost, retain its dated structural note with the access limitation or choose a supported alternative. Never silently replace an unavailable source with invented text.
