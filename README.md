# Kleo Personal Brand Skill — v0 design baseline

A reusable agent-skill design for LinkedIn personal branding and ghostwriting, informed by Kleo's public workflow.

This tag contains the [v0 specification](specs/v0.md). It is a design checkpoint, not an executable skill release. It was documented retrospectively on 2026-10-13; no historical v0 implementation snapshot is claimed.

The design covers author/product discovery, voice, client memory, content strategy, grounded writing and measured iteration. Browser access and external actions depend on the host's tools and user authorization.

This is an independent project, not an official Kleo integration or a copy of its proprietary prompts. An 85% parity target remains a benchmark question, not a guarantee.
